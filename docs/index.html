Game Engine Docs

A browser-first 2D/3D JavaScript engine with physics, input helpers, and a growing set of prototype demos.

Demo index 2D platformer 3D scene Physics

Core API

  • Game for canvas-based 2D loop and platformers
  • Sprite for draw, collisions, and simple visuals
  • Game3D for WebGL scenes and camera controls
  • Sprite3D for 3D cube-like actors

Physics

  • Physics2D.World and Physics3D.World
  • Body forces, velocities, restitution, friction
  • Simple AABB collision resolution for prototypes

Input

  • Keyboard listeners via registerKey()
  • Standard movement keys: WASD, arrow keys, space
  • Works in browser canvas contexts without extra setup

Basic example

const game = new Game("demo");
const canvas = document.getElementById("game");
game.setCanvas(canvas);

const box = new Sprite(40, 40, { color: "#60a5fa" });
box.setPosition(30, 30);
game.add(box);

game.start({
  update: () => {
    box.x += 1;
  },
  render: (ctx) => {
    ctx.clearRect(0, 0, canvas.width, canvas.height);
  }
});
